Why Veridrop

01

Cryptographic authenticity verification (exclusive)

Veridrop is the only tool in the industry that uses the Claude thinking signature — an Anthropic server-side cryptographic signature, 500-2000 characters long, that relays theoretically cannot forge. One test tells you whether it is real Claude.

02

All three protocols in one place, with automatic handoff

Claude / OpenAI / Gemini are all covered. Entered a GPT key on the Claude page? Veridrop recognizes it in a second and hands you off to the OpenAI page with one click — no re-pasting needed.

03

0.5-second preflight before submission

A relay claims to "support 50 models" but half are actually delisted? Veridrop pre-tests in 0.5 seconds before submission and tells you directly which ones work — so you don't waste half a minute waiting for an all-zero report.

04

Permanently shareable reports (HTML + JPG)

Every detection automatically generates a permanent /r/{id} link and a JPG card you can post straight to chat groups, forums, and communities. One image is all a friend needs to avoid a bad relay.

05

Fully open source · no possibility of key theft

API keys run in memory only and are discarded when the job ends — never written to logs or disk. With all code open source, you can audit the server or clone and deploy it on your own machine — far more transparent than closed-source "black-box" detection tools.

06

Field-level evidence · see exactly what the relay altered

Veridrop doesn't just give a "75" total — every deduction comes with concrete evidence: which keys are missing from the usage field, which streaming event was dropped, whether tool_use IDs follow the convention, how far the signature length deviates. You see at a glance where the relay tampered, not just a black-box number.

How to use it? Three steps, 60 seconds

  1. 1

    Enter the relay address + API key

    Pick the protocol page to test (Claude / OpenAI / Gemini), paste your base_url and key, and the model dropdown auto-lists the models your key can use on that relay.

  2. 2

    Click "Start Detection" and wait 30-70 seconds

    Veridrop runs 7-10 checks concurrently with live progress. Tokens consumed are billed to your key (~$0.012 with Haiku, ~$0.005 with GPT-4o-mini).

  3. 3

    Read the report, focusing on red and amber items

    Total ≥85 excellent (green) / 70-84 passed (light green) / 50-69 at risk (amber) / <50 failed (red). For Claude, focus on whether thinking signature scores 100; for OpenAI, check whether the usage field carries Claude / Gemini residue.

A score of 100 means different things per protocol

Claude's 100 includes cryptographic thinking-signature verification (an Anthropic server-side signature, unforgeable by relays); since OpenAI / Gemini lack an equivalent server-side signature mechanism, their verification strength only reaches the behavioral / protocol level. Every report page clearly labels which tier the detection belongs to at the top, preventing protocol compatibility from being misread as cryptographic proof of authenticity.
